# Agent Bench 网站框架

**结构讨论稿 v0.2 · 面向国际研究社区 · 最终文案以英文为主**

这一版只讨论内容顺序、取舍和篇幅。标题是候选栏目名，方括号是占位；任务范围、文案和实验结果都还没有定稿。

## 页面结构与建议占比

| 顺序 | 栏目 | 建议占比 | 当前建议 |
| --- | --- | ---: | --- |
| 01 | Overview / 项目概览 | 15% | 保留 |
| 02 | Motivation & Contributions / 动机与贡献 | 10% | 保留；可与首屏合并 |
| 03 | Tasks / 任务展示 | 25% | 核心；先选代表任务 |
| 04 | Evaluation / 如何评测 | 15% | 核心；保持简洁 |
| 05 | Results / 主要发现 | 20% | 条件保留；由实际证据决定 |
| 06 | Resources / 使用入口 | 10% | 保留 |
| 07 | Team & Citation / 团队与引用 | 5% | 保留；信息待补 |
| | **合计** | **100%** | **只是初始讨论方案** |

占比指页面的相对展示篇幅，不是严格的像素高度。删减模块后重新分配，不需要维持七个栏目。

## 01. Overview / 项目概览

**要回答的问题：** Agent Bench 是什么，读者为什么值得继续看？

**候选内容：** [项目名称与一句话定位]、[一个主视觉]、[报告与代码入口]。

> 版式占位：[左侧标题与一句介绍] ｜ [右侧视频或概念图]

**待决定：** 主线突出 benchmark、具身 agent 研究，还是评测平台？哪一个场景最能代表项目？

## 02. Motivation & Contributions / 动机与贡献

**要回答的问题：** 为什么做这件事，本项目的关键区别是什么？

**候选内容：** [一个研究问题]、[现有评测的相关缺口]、[最多三项贡献]。

> 版式占位：[一个问题] → [2–3 个贡献摘要]

**待决定：** 贡献重点是任务设计、评测方法还是系统？如果不足以独立成节，可以并入首屏。

## 03. Tasks / 任务展示

**要回答的问题：** 在哪些任务里评测 agent，这些任务为何有代表性？

**候选内容：** [少量任务家族]、[每类一个画面与任务目标]、[主要能力或挑战]。

> 版式占位：[任务家族 A] ｜ [任务家族 B] ｜ [任务家族 C]

**待决定：** 哪些家族进入本次发布？机器人变体如何组织？首页先做代表性展示，完整可检索目录作为独立页面的可选项。

## 04. Evaluation / 如何评测

**要回答的问题：** agent 怎样参与，一次评测如何产生可比较的结果？

**候选内容：** [一次交互流程]、[关键观测/工具/预算配置]、[成功与失败的基本判定]。

> 版式占位：[Agent] ⇄ [Environment] → [Evaluation]

**待决定：** 哪些规则要在网站说明，哪些链接到报告即可？是否需要单列能力等级或系统架构？具体分级和数值先留空。

## 05. Results / 主要发现

**要回答的问题：** 这个 benchmark 已经帮助我们发现了什么？

**候选内容：** [一张主结果图或表]、[1–2 条对应发现]、[简短的评测条件与范围]。

> 版式占位：[主结果图 / 表，暂不填数值]

**待决定：** 本版是否有正式模型对比？若只有平台或参考控制器验证，可改为 Current Status / 当前进展，并注明证据类型；也可以暂时移除。排行榜不是默认模块。

## 06. Resources / 使用入口

**要回答的问题：** 感兴趣的研究者下一步可以做什么？

**候选内容：** [Tech Report]、[Code + Quick Start]、[可选的数据/任务配置/示例]。

> 版式占位：[Read] ｜ [Run] ｜ [Explore]

**待决定：** 首次发布实际提供哪些资源？希望读者优先阅读报告、运行任务，还是接入自己的 agent？

## 07. Team & Citation / 团队与引用

**要回答的问题：** 谁在维护项目，怎样引用或联系？

**候选内容：** [作者与机构]、[引用信息]、[联系或反馈入口]。

> 版式占位：[Team] ｜ [Citation] ｜ [Contact]

**待决定：** 正式名称、作者顺序、机构标识和引用入口。未确认的信息保持占位。

## 可选内容与取舍

| 候选内容 | 默认处理 | 加入条件 |
| --- | --- | --- |
| 完整任务目录与搜索 | 可选独立页 | 范围稳定，确有逐项查阅需求 |
| Leaderboard | 暂不建立 | 有统一条件下可比较且可更新的结果 |
| 多段演示视频 | 先留一个主视觉 | 不同视频分别说明独立贡献 |
| 详细架构、API、安装步骤 | 文档或报告 | 与核心方法直接相关的部分才进首页 |
| 逐项历史验收记录 | 补充材料 | 支撑具体公开主张时引用 |
| News / Updates | 可选 | 有持续维护计划 |

## 优先讨论的三个决定

1. **主线：** 最希望研究者记住的贡献是什么？
2. **范围：** 哪些任务、机器人和评测设置属于这一版？
3. **展示深度：** 网站做精简项目展示，还是同时承担任务浏览工具的角色？

可以直接按“保留 / 合并 / 删除 / 调整占比”批注，确定后再写英文文案和选择图表。
